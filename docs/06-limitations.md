# 已知边界与未验

> 这一页是**诚实清单**，不美化：哪些东西**没实现**、哪些判定**会漏**、哪些结论**只有代码级证据**。
> 读法：每条给「现状 / 影响 / 出处」三段；「未验」一律标出未验，**不当作已验**。

## A. 未实现（有规格、没有一行代码）

### A1 `bootstrap_project` 未实现

- **现状**：只有规格（参数表、三档口径、执行阶梯与回执形状都已写死）——**代码一行未写**。前置条件卡在：`create_domain_session` 的编排没有抽成可复用函数，全写在 `execute` 闭包里（约 547 行）；bootstrap 想复用「建会话＋权限＋标题＋置顶＋排任务」这条阶梯，只能 ① 先抽成导出函数（要重跑 smoke）或 ② 复制一份（两处口径会漂）。
- **影响**：「为一个项目建骨架」目前**只能手工或脚本**做；仓库 README 的「快速开始」是设计目标，不是现状。且它建会话前必须过四级 OR 暂停闸，否则就成了「已暂停」的后门。
- **出处**：`{体系根}/_pages/插件自动化与GUI准备-2026-10-18.data.js` §三（工具规格）、§八（硬约束）、§九（还没做的）；`README.md`「快速开始」节。

### A2 GUI 侧栏页未实现

- **现状**：挂载点已**实测**（宿主已有 `sidebar.panellist` 侧栏入口行 + `main` 整页容器两个 root 作用域 slot；第三方唯一先例整个客户端文件只有 21 行）；但 `lib/client.js` **一行未写**。宿主半边的空壳 + 一个最小只读页属下一轮。
- **影响**：现在**没有界面**——所有操作都要"在会话里说一句、AI 调工具"；只读数据面（读 `_registry/*.json` 与域名册）也还没有页面承载。
- **出处**：`{体系根}/_pages/插件自动化与GUI准备-2026-10-18.data.js` §七（挂载点与只读数据面）、§九。

### A3 退役机制不存在（`retire_session` 未实现）

- **现状**：**「退役」在会话级没有对应档位**——`markRetired` 只挂域动作，主会话够不着；插件里也**没有 `retire_session` 这个工具**。当前做法是「真值登记 ＋ 自己用 `set_domain_state(scope=session)` 把自己暂停」**近似**，并把「标题标记做不到」如实记进源记录的用例里。
- **影响**：退役**不是**一个可调的原子动作，而是一套人工约定；没有"标题标记"、没有一次性收尾。想真做需要新增工具（会打断现有工具集断言，见 D2）。
- **出处**：`{体系根}/_registry/DOMAIN-JUDGMENTS.md` 判断记录（体系主会话换届退役那行：`markRetired` 只挂域动作、以「登记 ＋ 会话级暂停」近似）。

## B. 判定不完美（会漏拦、会复活）

### B1 项目级暂停不读会话存档 ⇒ 判不出就不拦（标 `unresolved`）

- **现状**：项目级判定**不查会话存档**：「离线**且**无在任声明」的会话推不出所属项目 ⇒ 按「拿不到就不拦」处理，并在回执里标 `unresolved`（写明哪一级没判成）。姊妹断言真机已过（判不出 ⇒ 不拦，但 `unresolved` 如实给）。
- **影响**：**项目暂停拦不住这类会话被 `wake` 叫醒**（投递本因离线被拒）；且域键＝`项目:域`、裸短名给不出项目 ⇒ 该级"结构上不存在"，进 `unresolved` 的是**会话级与项目级**。
- **出处**：`plugins/dsh-domain-bridge/README.md` §四级「已暂停」（降级不静默、`unresolved`）；`{体系根}/SYSTEM-OVERVIEW.md` §三「已暂停」政策轴（已知限制 ①）；`{体系根}/会话协作框架.md` §八（已知限制 ①）。

### B2 域终结后，取消的暂停会随重新认领「复活」

- **现状**：域被 `release_domain` 终结后派生状态＝**已终结**（暂停轴失去意义），**但状态记录留在盘上**（墓碑专门记了「终结时仍处于暂停」）⇒ **同一个 key 日后被重新认领时，这条老暂停会复活**，往它投消息会**静默入队**。
- **影响**：终结 ≠ 清零；重新认领一个老域可能**一上来就是"已暂停"**，人得先显式 `active` 解开。代码没清是因为 `release_domain` 只合并 `terminatedAt`、**不清 `paused`**——要真作废只需 release 时顺手清一行，**未做、待用户改口**。⚠️ **不许写成「暂停随之作废」**。
- **出处**：`plugins/dsh-domain-bridge/README.md` §边界（「已终结」的墓碑只有本插件写的才有）；`{体系根}/SYSTEM-OVERVIEW.md` §三（域退役之后的暂停）；`{体系根}/会话协作框架.md` §八「域退役之后的暂停」。

### B3 另两条如实记账的回执异常

- **现状（1）**：`release_domain` **未暂停时也恒带** `pausedScopes: []` / `pausedByScopes: []`（与 `claim_domain` 的「零键」不同——这是例外）。
- **现状（2）**：拦截回执里 `matchedBy` 在「**裸短名走索引标注**」这条路径上仍回 `'declaration'`——该值是兜底，**不代表真有声明**。
- **影响**：按"claim 的零键规则"读 release 回执会读错；据 `matchedBy` 去找／认领那条"声明"会**找不到东西**。
- **出处**：`{体系根}/SYSTEM-OVERVIEW.md` §三（已知限制 ②③）；`{体系根}/会话协作框架.md` §八（已知限制 ②③）。

## C. 能力边界

### C1 插件只管「插件介导」的那条路

- **现状**：人自己在 GUI 点开那条会话、或宿主自己 resume——**插件拦不住**，那正是「人工手动唤起」，也是暂停语义里刻意留的口子。停机通知 `notifyPredecessor` 也刻意**绕开暂停闸**（止损优先），四级都不走。
- **影响**：暂停期间，一个**已经跑着的**域会话照样能改文件；插件能做的只是"不再往里递新活"。判"这个域有没有人管"看的是**在任声明 ＋ 在线**，而不是"窗口还能不能收发消息"——**离线／已终结 ≠ 失联**。
- **出处**：`plugins/dsh-domain-bridge/README.md` §边界；`{体系根}/会话协作框架.md` §八「诚实边界」。

## D. 工程护栏的缺口

### D1 `282 用例 / 54,624 断言`这个基线没有任何断言守着

- **现状**：smoke 的 summary 只**打印** `分支用例 / 深度扫描节点 / 无损往返断言 / 分支断言`，**不断言这些数字** ⇒ 数字只能靠**改前改后人眼比对**。
- **影响**：如果有人删掉/跳过一整段测试而没改代码，smoke **照样全绿**；唯一防线是"每次改插件前先跑一遍基线、改完再比一次"这个人工仪式。
- **出处**：`plugins/dsh-domain-bridge/test/smoke.mjs` summary 段；`plugins/dsh-domain-bridge/CHANGELOG.md`（每次改动的验证行）；`{体系根}/_pages/插件自动化与GUI准备-2026-10-18.data.js` §八。

### D2 加第 12 个工具会打断 3 处断言

- **现状**：`apply()` 后断言工具集**逐字相等**（`test/smoke.mjs:320`），另有 `registered.size === 11`（`:391`）与版本字面量（`:398`）三处。
- **影响**：新增任何工具**必须同一批改测试**，否则 smoke 全红；这也意味着 A1（bootstrap）与 A3（退役）落地时，测试与版本号要一起动。
- **出处**：`plugins/dsh-domain-bridge/test/smoke.mjs:320,391,398`；`{体系根}/_pages/插件自动化与GUI准备-2026-10-18.data.js` §八。

## F. 实验性：接口与目录结构仍会变

- **现状**：仓库自述状态＝**实验性 / 半成品**——这是作者本人在用的工作系统，**接口与目录结构仍会变**，别当稳定版依赖。插件自身也在 0.x：**次版本号变化＝行为变化**，修订号＝缺陷修复与内部瘦身。
- **影响**：工具的参数与回执形状、状态文件布局、文档路径都可能在不打招呼的情况下变；使用者应收敛到"这台机器上跑通"（并每次改前跑基线），而不是长期锁某个 0.x 行为。
- **出处**：`README.md` 顶部状态行；`plugins/dsh-domain-bridge/CHANGELOG.md` 版本约定；`plugins/dsh-domain-bridge/package.json`（version / engines）。
