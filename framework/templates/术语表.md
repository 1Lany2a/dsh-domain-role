# 术语表（体系口径唯一源）

> 用途：**所有活文档、派发指令、提案、会话开场白一律以本表为准。**
> 建立：2026-10-09（用户拍板统一）。起因：用户察觉"体系里名词不统一"，且"**域会话 / 域窗口**"两词并用却**从未定义过区别**。
> 改前快照：`{回收站}\dsh\2026-10-09\术语统一-改前快照\`（8 份）。详见 `templates\SYSTEM-changelog.md` 2026-10-09「术语统一第二轮」。
> **读取层级**：本文件是 🔴（按需读）；**最小对照**已写进 `templates\dispatch-template.md` 域会话节（🟡）。

## 一、怎么用

1. **写任何体系文档前**先看本表（尤其第六节"禁用词"）。
2. **新增一个机制 / 概念** ⇒ 必须在本表登记一行；**一个口径只有一个词**（防"同一口径写多处、总有一处先烂"）。
3. **历史不动**：`changelog`、`projectlog`、旧提案与历史报告里的旧词**一律不改**（改了会破坏历史记录）；必要时加一行"已改称 X"。
4. **不做机械全局替换**（2026-10-01 已定）：只改活文档里**指当前事物**的用法。

## 二、官方 / dsh 的东西（外部概念，只做对照；**我们一律不引入**）

| 概念 | 定名 | 说明 |
|---|---|---|
| dsh 内置多 agent 机制 | **官方团队**（`dsh-experimental-agent-team`） | ⛔ 不叫"智能体团队"——**它不是团队，我们也不引入** |
| 它的队长 | **Lead** | ⚠️ **不许叫"主会话"**（那是我们的词） |
| 它的成员 | **官方成员** / `teammate` | 与"域会话"严格区分 |
| 它的状态表 / 任务表 / 邮箱 | **官方名册** / **官方任务板** / 官方邮箱 | 与"使命库"区分 |
| 第三方 `dsh-agent-team-gui` | **第三方小队** | 已装未启用 |
| dsh 的子代理 | **子代理**（subagent） | ⛔ 禁用：子会话、子智能体 |
| zcode 的 Explore | **zcode 子智能体** | 另一个工具，保留原名以免混淆 |

## 三、我们的角色与载体

| 概念 | 定名 | ⛔ 禁用 / 备注 |
|---|---|---|
| 三级会话 | **主会话 / 副会话 / 域会话** | 主 Agent / 副 Agent |
| 用户手开的会话窗口 | **窗口** | 别用"会话"单指窗口 |
| 长期负责某方面的身份（跨窗口存续） | **域** | 域的**资产归属**与域会话的**职责**是同一个"域" |
| 承载某域的那个执行会话 | **域会话** | ⛔ **"域窗口"已退休**（2026-10-09）；口语可说"那个窗口" |
| 当前代表某域的那个会话（**身份**，不是载体） | **负责人** | **一个域同时只有一个负责人**（一对一不变量，2026-10-09 用户裁定）⇒ 同域多在线＝**违规状态**、不是容错；并发需求由负责人派**子代理**承担 |
| 一个窗口长期干一个域的**布局** | **一域一窗口** | 与「一任务一窗口」对称；⛔ 别再写"域窗口（布局）" |
| 会话的 cwd 分组单位 | **工作区** | dsh workspace（如 `{体系根}\tixiweihu`） |
| 同一仓库的多个检出目录 | **worktree** | ⛔ 不要造"域工作区"；两词**不许互换** |
| 使命编号 | `S##-<域>-<slug>` | 域写在编号里 ⇒ **域是跨窗口的身份** |
| 域的知识沉淀 | **域文档**（`KNOWLEDGE\<域>.md`） | ⚠️ 一个域会话可横跨多个工作区 ⇒ **副本可能不止一份，同步责任在该域会话** |
| **谁现在代表某个域**（事实，只能人来声明） | **在任声明** | `{体系根}\_registry\domains.json`：一行一个域，key＝`<项目>:<域>`；只存"当前在任"，不存历史/任务/状态。与"域名册"不是同一个东西（2026-10-10 裁定） |
| 域清单 + 各域历史用过哪些会话（**派生快照**，不新建存储） | **域名册** | 从使命库 + 索引派生；**"当前负责人"不在其内**，那属"在任声明"（2026-10-10 裁定） |

## 四、通信与状态（2026-10-09 新增；**概念模型**见 `{体系根}\会话协作框架.md`，**落地侧**见《提案 2026-10-09-会话互通与子代理》）

| 概念 | 定名 |
|---|---|
| 本机制（给域加一个通信面） | **域可达层** |
| 双方能互相发消息 | **互通** |
| 把消息送过去（动作） / 消息到了（结果） | **投递** / **送达** |
| 目标会话还开着、能投递 | **在线** |
| 目标会话已关 / 已交接 | **离线** |
| 这个域以后不做了 | **终结** |
| 找不到目标 | **不可达** |
| 换窗口这件事 | **交接**（正式）；"换人"仅口语 |

> **"死亡"不是正式词**：正式文档用 **离线 / 终结** 两档；"死亡"只作口语总称。

## 五、四组必须分开说的近似词

| 别混 | 各自指什么 |
|---|---|
| **使命** / **任务卡** / **待办** / **官方任务板** | 使命＝登记单位（`S##-…`）；任务卡＝派给项目的一段指令文本；待办＝TODO 区；官方任务板＝官方团队的 task board |
| **会话** / **窗口** / **工作区** / **worktree** | 会话＝dsh 的运行实体（**含子代理**）；窗口＝**用户手开**的那个；工作区＝dsh 的 cwd 分组；worktree＝git 检出 |
| **域** / **域会话** / **域文档** | 域＝身份（跨窗口存续）；域会话＝当前承担它的那个会话；域文档＝该域的知识文件 |
| **子代理** / **官方成员** | 子代理＝父会话派的 dsh subagent（可 cold-resume，但**不是**独立顶层会话）；官方成员＝官方团队名册里的 teammate |

## 六、⛔ 禁用词总表

| 禁用 | 改用 |
|---|---|
| **域窗口** | **域会话**（布局名用「一域一窗口」） |
| **域工作区** | **工作区** 或 **worktree**（按实际所指） |
| **子会话**（指 dsh subagent 时） | **子代理**（"子会话登记表"等**历史专名保留**，不改） |
| **子智能体**（指 dsh subagent 时） | **子代理**（zcode 的 Explore 除外） |
| **智能体团队** | **官方团队**（外部）或 **域可达层**（我们的机制） |
| **死亡**（正式文档） | **离线 / 终结** |

## 七、维护

- 新增 / 改名词 ⇒ 改本表 + 改活文档里**指当前事物**的用法 + `SYSTEM-changelog.md` 记一笔；**历史一律不动**。
- 往 🟡 层（`dispatch-template.md` / `SKILL.md`）加术语对照时，**按置换原则同减一条**。
- ⚠️ 本表与 `dispatch-template.md` 域会话节**不得各写一套**：节里只放**最小对照**，细节一律指回本表。
